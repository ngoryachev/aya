# Состояние

## Проверено

**Автотесты (35, без сети, на имитациях агентов и исполнителя):** полный цикл от цели до приёмки, маршрут решения к эксперту и обратно, уроки стиля, политика контента, запись в трекер, автономия по ступеням, изменение принятого решения, паузы, перехват задачи, неактуальные задачи, молчание эксперта, ИИ-подмена, лимит обращений, прецеденты, перезапуск исполнителя, стопка веток и доработка, слияние с делегированием, защита от молчаливых остановок, ограничение сессий, уведомления владельцу, HTTP-слой.

**Консоль владельца:** пройдена в браузере на демо-сценарии, весь путь владельца кликами, без ошибок.

**Настоящие агенты и настоящий sdlc на тестовом репозитории:**
1. Простая задача: от цели до PR и приёмки тестировщиками, около 7 минут.
2. Решение, которое обязан принять эксперт: разработчик не начинает без него, пакет решения уходит через утверждение контакта и одобрение, исполнитель реализует выбранный вариант.
3. Сложная цель из четырёх зависимых задач, 23 минуты: архитектор принимает общее решение и пишет его в память проекта, два разработчика работают параллельно, зависимые задачи стартуют от ветки незавершённой, техлид закрывает рядовые чекпоинты сам (автономия второй ступени, решения идут владельцу на просмотр), ИИ-подмена эксперта отвечает на обратимый вопрос, тестировщики принимают пакет, техлид сливает четыре PR снизу вверх, владелец получает уведомления в Telegram.
4. Две задачи стопкой со слиянием через техлида, после ограничения сессий: расход агентов около $2.7 против $18 в прогоне 3.

## Найдено и исправлено настоящими прогонами

- Решение запросил один агент, а ждал его другой: исполнителя задачи никто не будил, работа молча вставала. Теперь о решении по задаче узнаёт и её исполнитель, а о задаче без движения система напоминает.
- После сбоя исполнителя задачу нельзя было запустить заново.
- Агенты обменивались сообщениями, не требующими действий.
- Задача стартовала от основной ветки, когда её зависимости были приняты, но ещё не слиты.
- Сессии агентов росли без ограничения, и каждый следующий ход стоил дороже.

## Не проверено на настоящем исполнителе

- Возврат задачи на доработку и обновление задач, начатых от её ветки: только на имитации.
- Урок стиля из правки текста владельцем: на настоящих агентах проверено только правило, добавленное словами.
- Автономия третьей ступени, отмена решения владельцем, перехват задачи, неактуальные задачи: только автотесты.

## Не сделано

- Настоящие каналы: Slack, почта, трекер компании. Шлюз работает с имитациями за двумя интерфейсами (канал и трекер).
- Удалённые узлы.
- Уведомления ведут на локальный адрес консоли: с телефона ссылки не открываются, пока сервис не доступен из сети.
- Сводка накопленных уроков стиля в единое руководство: сейчас это редактируемый список.
- Разрешение конфликта мнений двух экспертов как отдельный сценарий: сейчас решает владелец через изменение решения.
