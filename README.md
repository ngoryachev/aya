# aya

Виртуальная команда агентов для разработки ПО. Агенты с ролями и иерархией сами ведут задачи, а люди участвуют в разворотных решениях: владелец классифицирует решения и утверждает всё, что уходит наружу, живые эксперты отвечают на вопросы через единый шлюз.

- [Спека](docs/SPEC.md)
- [Состояние: что проверено и что дальше](docs/STATUS.md)

## Что уже работает

- **Команда:** ПМ, техлид, архитектор и два разработчика одной фулстек-роли, с подчинением. У каждого агента карточка, своя память и своя сессия Claude (Agent SDK).
- **Задачи:** внутренний граф с зависимостями, входной контроль перед работой, связь с задачей в трекере компании, статус «неактуальна» без удаления наработок.
- **Цикл решения:** кандидат с самооценкой агента → классификация владельцем (или автономия по классу) → решающий (сам агент, другой агент, эксперт, владелец) → подкрепление → прецедент. Необратимые решения автономию не получают.
- **Шлюз:** утверждение контактов, политика исходящего контента, одобрение сообщений с правкой, уроки стиля с охватом (адресат, роль, все), запись в трекер, разбор ответов как данных.
- **Стопка веток и слияние:** зависимая задача стартует от ветки незавершённой зависимости; сливает владелец или, если он делегировал, техлид, снизу вверх и только принятое тестировщиками.
- **Исполнитель:** sdlc за общим интерфейсом. Его чекпоинты приходят техлиду, ответ техлида проходит цикл решения.
- **Консоль владельца:** решения, сообщения, задачи, команда, стиль, автономия, лента событий, имитатор внешнего мира. Пауза, прерывание хода, перехват задачи, изменение принятого решения.

Настоящие каналы (Slack, почта, Jira) пока не подключены: шлюз работает с имитацией, за людей снаружи отвечает владелец на странице «Внешний мир».

## Запуск

Нужны Node 22 и Claude Code CLI с выполненным входом. Для работы с кодом нужен запущенный sdlc на этой же машине.

```bash
npm install
npm run build
npm start            # печатает ссылку вида http://127.0.0.1:7450/?t=<токен>
```

Параметры: `--port`, `--host`, `--home` (каталог данных, по умолчанию `~/.aya`), `--model` (модель агентов по умолчанию), `--telegram sdlc` (уведомления владельцу через бота, которого уже использует sdlc; свой бот задаётся переменными `AYA_TELEGRAM_TOKEN` и `AYA_TELEGRAM_CHAT`), `--public-url` (адрес консоли в уведомлениях).

## Демо без Claude и без sdlc

```bash
npm run demo         # агенты и исполнитель имитируются сценарием, сервер и интерфейс настоящие
```

## Разработка

```bash
npm run typecheck
npm test             # полный цикл на имитациях, без сети
```

- `src/team.ts` — задачи, события, очередь пробуждений агентов.
- `src/decisions.ts` — цикл решения, автономия, прецеденты.
- `src/gateway.ts` — граница с внешним миром.
- `src/executor.ts` — исполнитель и его чекпоинты.
- `src/tools.ts` — инструменты, через которые агенты меняют состояние.
- `src/runtime.ts`, `src/sdk-runner.ts` — ходы агентов.
- `src/http.ts`, `ui/` — API и консоль владельца.
- `prompts/` — общие правила и роли.
