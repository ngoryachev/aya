# aya

Виртуальная команда агентов для разработки ПО. Агенты с ролями и иерархией ведут задачи сами, а люди участвуют в разворотных решениях: владелец классифицирует решения, живые эксперты отвечают на вопросы через единый шлюз во внешний мир.

Статус: в разработке.
